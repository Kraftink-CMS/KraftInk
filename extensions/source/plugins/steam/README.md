# Steam

Steam is bundled with KraftInk. Enable **Steam** in **External connections** to offer OpenID sign-in. Members can link Steam under **My account → Connections**. For games that use Steam identities, linking verifies the member’s Steam account.

An optional Steam Web API key enables public profile lookups and Steam avatars.

[External sign-in guide](https://kraftink.com/en/documentation/oauth) · [Game identity guide](https://kraftink.com/en/documentation/games#verifying-identities)
