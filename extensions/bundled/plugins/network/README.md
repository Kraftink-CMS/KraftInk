# Network

Network is bundled with KraftInk and enabled by default. It lets KraftInk recognise visitor IP addresses and HTTPS when requests arrive through a trusted proxy.

Open **Plugins → Network → Configure**. Choose **Direct connection** if visitors reach the web server directly, **Cloudflare** to use its bundled network ranges, or **Custom proxy** to enter the IP addresses or CIDR ranges provided by your host. After saving, check the detected address on the same page. Disabling Network restores direct connection handling.

[Domain and proxy guide](https://kraftink.com/en/documentation/configuration#domain-and-proxy)
